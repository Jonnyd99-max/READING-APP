# Help MeeHee Read

A bright, interactive reading adventure for children aged 6–9.

## First-version features

- Three themed, choice-driven stories
- Tappable tricky words with browser speech and phonics breakdowns
- A saved-word recap collection
- Stars, reading progress, and family-configured rewards
- A grown-up progress view and changing proof code
- Device-local progress storage, with no child account or personal-data collection

## Run locally

Open `index.html` in a modern browser, or serve this directory with any static web server.

This dependency-free app can be hosted directly using GitHub Pages.
